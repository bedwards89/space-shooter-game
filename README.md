# STARWAKE

A 2D retro side-scrolling shoot-'em-up in the R-Type / Gradius tradition. Built with Phaser + Vite, hosted on GitHub Pages.

**Live game:** https://bedwards89.github.io/space-shooter-game/

> Status: Phase 0 — foundation scaffolded, assets not yet integrated.

---

## How to play

| Action | Keys |
|--------|------|
| Move | Arrow keys or WASD |
| Fire | Space or J |
| Pause | P or Esc |
| Confirm in menus | Enter or Space |

Shoot enemies, collect power-ups, defeat bosses, clear all three levels.

---

## Run locally

```bash
git clone https://github.com/bedwards89/space-shooter-game.git
cd space-shooter-game
npm install
npm run dev        # dev server at http://localhost:5173
npm run build      # production build → dist/
npm run preview    # serve dist/ locally
npm test           # unit tests
```

Node.js LTS ≥ 20 required (see `.nvmrc`).
