# Accessibility

## Requirements (non-negotiable for v1)

| Requirement | Status |
|-------------|--------|
| Keyboard-only: every menu and pause reachable without mouse | Phase 2 |
| Pause (P / Esc) reachable from any gameplay frame | Phase 2 |
| Arrow keys AND WASD both work for movement | Phase 3 |
| Space AND J both work for fire | Phase 3 |
| Color is never the only signal (power-ups differ in shape AND color) | Phase 5 |
| Audio is never the only signal (every audio cue has a visual counterpart) | Phase 8 |
| No strobe / flash faster than 3 Hz | Phase 10 |
| HUD and menu text contrast ≥ WCAG AA | Phase 9 |
| Volume sliders for music and SFX; muting works at 0% | Phase 8 |
| First user interaction unlocks audio context (no autoplay) | Phase 8 |
